Ce que fait la page aujourd’hui

Quatre champs, un clic, et le client part sur WhatsApp

Vérifié le 28/10/2026 dans le navigateur, sur desktop et mobile. La page est bonne : titre, voiture, zone, nom du chauffeur, FAQ et données structurées corrects. C’est le formulaire qui demande du travail.

Aujourd’hui

« Reservar » fait seulement défiler jusqu’au formulaire

Formulaire : Départ, Arrivée, Date, Heure. La validation en ligne fonctionne.

Envoi : ouvre api.whatsapp.com dans le même onglet avec le message prêt (inclut la distance calculée).

Rien n’est enregistré : aucune écriture côté serveur, aucun événement analytics au clic.

Questions manquantes : passagers (la FAQ le promet), type de service, aller-retour, vol, nom.

Autocomplétion sans frontière : propose Ajaccio, Nantes et Lille pour « Aéroport de N ».

Poids : 4,9 MB par visite ; l’image de partage (og:image) répond 404.

Fait × hypothèse : tout ce qui précède est un fait vérifié sur la page. Les écrans « ce qu’il faut obtenir » des slides suivants sont une proposition.
