## Achado: desfazer não reverte inserção

`desfazer.js` só restaura as linhas antigas, por UPSERT. Uma linha inserida continua lá depois do desfazer. `executar.js` classifica o arquivo só com INSERT como reversível, com o motivo "nada a reverter".

Efeito na Fase 3: cada casa nova entra com `published = false`, então um erro não aparece no site. Mas a remoção exige um DELETE por id, com backup declarado, pela porta. O SQL de captação precisa gravar a lista de ids inseridos.
